# 2026-07-28：命令规范化解析器

## 今日目标

按 ADR-0009 §4/§5 实现命令解析器——这是规则引擎、高危拦截、git 写识别、工作区判定的共同前置
件。纯函数、无副作用、重绕过用例测试。本日只做「把命令解析成结构 + 分类」，不做裁决。

## 开发指导

- **复合拆解**：识别 `&& || ; | |& & 换行`，拆成子命令；整条裁决取最严（本日只产出子命令列表，
  裁决在 07-29）。
- **命令替换 / 进程替换扫描**：`$(...)`、反引号、`<(...)` 内部内容一并纳入解析，`echo "$(rm -rf
  ~)"` 的内层删除可被识别。
- **进程包装器剥离**：`timeout time nice nohup stdbuf`、无标志 `xargs` 剥离后匹配内层；
  `watch setsid ionice flock`、`find -exec/-delete` 标记为「永远提示」；`npx docker exec devbox
  run mise exec direnv exec` 不剥离、须连内层匹配。
- **分类识别**：只读命令集（`ls cat echo pwd head tail grep find wc which diff stat du cd` +
  git 只读）、文件操作命令集（`mkdir touch rm rmdir mv cp sed`）、危险目标（`rm -rf` 目标为
  `/`/`~`/`.`/`./*`/`*`/`..`/工作区根/区外绝对路径）、git 写命令、路径抽取（参数中的读写目标）。
- **安全环境前缀**：`LANG=C`、`NO_COLOR=1` 等只读环境变量前缀在匹配时忽略。
- 解析不出结构时：标记为「未知」，交由上层落默认 ask、高危不误伤也不硬拦。

## 非目标

- 不做 deny/ask/allow 裁决（留 07-29）；解析器只输出结构与分类标签。
- 不实现 glob 规则匹配（留 08-04）。

## 最终产物

- 命令解析器模块（子命令拆解、替换扫描、包装器处理、分类与路径抽取）。
- 密集的绕过用例测试：不同空格 / 引号 / `~` 展开 / 绝对相对路径 / 复合 / 替换内部 / 包装器嵌套。

## 验收重点

- `git status && rm -rf ~` 拆出两个子命令，`rm -rf ~` 被识别为危险目标。
- `echo "$(rm -rf ~)"` 的替换内层被扫描出删除。
- `timeout 30 npm test` 剥离后等同 `npm test`；`devbox run rm -rf .` 内层被识别。
- 解析器为纯函数，无 IO、无副作用。

## 验收命令

```bash
make ci
```
