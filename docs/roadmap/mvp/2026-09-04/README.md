# 2026-09-04：终端 TUI 信息层级与配置体验优化

## 目标

在不修改 Agent、工具、安全策略和 Web 前端的前提下，优化 `forge --cli` 的窄屏可读性、
斜杠命令发现、对话层级、审批决策和配置编辑体验。

## 实现范围

- 斜杠菜单增加命令分类、显式选中光标、统一语义色与中文关键词检索；候选保持 Claude
  Code 风格的单行扫描结构。配置菜单也保持单行选项，界面、日志、执行、模型在顶部横向
  切换。
- 菜单置于输入框上方；输入高度、状态文本和启动横幅按终端尺寸退让。
- `/help` 按与命令菜单相同的分类展示。
- 对话不显示角色文字标签，仅用颜色分层：用户正文白色、助手正文青色、工具时间线浅灰；
  完成行补充可用的 token 分项。
- 审批采用摘要优先、详情按需展开，交互式默认焦点为拒绝。
- `/config` 展示值、来源、作用域、生效时机，并支持删除覆盖、恢复 SCHEMA 默认值。
- 修复帮助文案允许留空而配置校验拒绝空值的不一致。

## 边界

- 不采用全屏 alternate buffer，保留原生终端滚动历史。
- 不改变审批词汇、权限策略、工具执行与取消语义。
- 不在 TUI 直接读写配置文件；所有写入和 reset 继续经过 `ConfigService`。
- 不修改现有 Web 前端；共享配置声明向后兼容现有 settings API。

## 验收

- 80×24 终端中启动信息、命令菜单和输入区均可使用，不出现主要操作被推出屏幕的情况。
- `/日志` 能检索到 `/config`，英文前缀匹配顺序保持稳定。
- 配置菜单能区分默认值与用户覆盖、应用级与项目级；reset 后覆盖键从 JSON 中删除。
- `logging.directory` 与 `logging.max_value_chars` 可合法保存空值。
- 审批直接回车选择拒绝；查看详情不会产生 broker 决议。
- TUI 与配置服务相关测试通过，完整测试与静态检查通过。
