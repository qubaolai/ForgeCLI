# ForgeCLI MVP 阶段开发计划

## 1. 周期

- 起始日期：2026-06-17
- 结束日期：2026-08-11
- 工作日数量：40 天
- 阶段目标：交付一个可本地安装、可持续对话、可恢复、可受控执行的软件工程 CLI Agent MVP。

## 2. MVP 范围

MVP 必须包含：

- 本地 CLI 会话。
- `events.jsonl` 和 `state.json`。
- `chat`、`plan`、`act` 三种模式。
- 配置模块。
- `AgentWorkflow` 抽象和 `BuiltinWorkflow`。
- 基础工具：文件读取、搜索、shell、git、测试命令。
- 工具风险分级和审批。
- session resume。
- context compact。
- 基础 inspect/status。

MVP 不包含：

- 完整 Multi-Agent。
- AutoGen adapter。
- 真实 MCP server 深度集成。
- Skills 完整生态。
- 企业审计数据库。
- 云端服务。

## 3. 阶段拆分

| 阶段 | 日期 | 目标 |
| --- | --- | --- |
| M0：开发准备 | 2026-06-17 至 2026-06-19 | 明确实现边界、任务拆分、验收模板 |
| M1：工程骨架与领域内核 | 2026-06-22 至 2026-07-03 | 项目结构、配置、领域模型、事件和状态存储 |
| M2：对话循环与模式策略 | 2026-07-06 至 2026-07-17 | CLI 会话、chat/plan/act、AgentWorkflow、上下文包 |
| M3：工具系统与审批 | 2026-07-20 至 2026-07-31 | Tool Registry、内置工具、风险分级、审批、artifacts |
| M4：恢复、压缩与 MVP 验收 | 2026-08-03 至 2026-08-11 | resume、compact、inspect、E2E、硬化和 MVP 验收 |

## 4. 每日验收格式

每天结束时，开发者需要提交：

- 今日完成的代码范围。
- 关键文件列表。
- 运行过的测试命令和结果。
- 与设计文档不一致的地方。
- 遗留风险和明日建议。

我按对应日期目录的验收标准检查。
