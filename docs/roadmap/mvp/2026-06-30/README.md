# 2026-06-30：配置命令

## 今日目标

提供用户可操作的配置命令。

## 开发指导

- 实现 `forge config list/get/set/unset/validate` 的 MVP 版本。
- `set/unset` 只允许修改用户或项目配置，不修改企业策略。
- 配置写入使用 TOML，并尽量保留格式稳定性。
- 禁止通过命令写入 API key、token、secret 等敏感值。

## 最终产物

- 配置 CLI 命令。
- 配置命令测试。
- 配置错误提示样例。
- `.forge/config.toml` 示例。

## 代码验收

我会检查命令行为是否清晰，是否能防止用户绕过安全配置，是否没有把配置逻辑写死在 CLI 层，是否不会把敏感凭证写入配置文件。
