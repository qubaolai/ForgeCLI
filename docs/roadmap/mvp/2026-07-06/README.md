# 2026-07-06：CLI 会话入口

## 今日目标

实现基础交互式会话入口。

## 开发指导

- `forge` 在当前目录启动默认交互式会话，并绑定当前目录为 `workspace_root`。
- `forge chat` 明确启动 chat 模式。
- 若存在可恢复 session，提示恢复最近会话或创建新会话。
- 用户输入写入事件日志。
- assistant 可返回占位响应。

## 最终产物

- 交互式 CLI。
- 用户消息落盘。
- 当前目录 workspace 绑定。
- 会话安全退出路径。
- 基础 smoke test。

## 代码验收

我会检查 CLI 是否围绕 session 运行，是否没有把对话状态放在内存里不可恢复，裸 `forge` 是否能进入可持续对话而不是只执行一次命令。
