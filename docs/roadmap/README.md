# ForgeCLI 研发排期索引

本目录用于放置按阶段和日期拆分的研发排期、每日目标、验收标准和最终产物要求。

当前已规划：

- [MVP 阶段开发计划](mvp/README.md)：2026-06-17 起滚动推进；当前计划覆盖 2026-06-29 至 2026-07-10，重点落地统一 LLM gateway。
- [后续迭代 Backlog](backlog.md)：MVP 阶段显式不实现、留待后续大版本迭代的能力汇总登记表，每条对齐目标阶段。

## 协作方式

- 开发者按每日目录中的目标完成实现。
- 每日结束时提交对应验收材料：代码 diff、测试结果、设计偏差说明、遗留问题。
- 我负责按当天验收标准检查，不直接修改代码。
- 如果实际开发偏离计划，需要先更新当天文档或新增偏差记录，再继续开发。
