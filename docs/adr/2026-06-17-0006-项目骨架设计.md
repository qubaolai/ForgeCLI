# ADR-0006：项目骨架设计

## 状态

Accepted

## 日期

2026-06-17

## 背景

规范项目目录结构、Python 版本、包管理器、测试工具、lint 和 typecheck。MVP 阶段应建立可运行、可测试、可安装的最小骨架，但不提前创建未来阶段才需要的空模块。

## 决策

1. Python 版本为 3.13+。

2. 包管理器采用 **Poetry**，提交 `poetry.lock` 以保证依赖解析确定性。

3. 测试工具使用 **pytest**。

4. lint 和 format 使用 **Ruff**。

5. typecheck 使用 **mypy**。

6. 项目采用 `src/forgecli + tests` 布局。

7. MVP 骨架仅创建当前阶段需要的文件和目录。目标架构仍按 DDD 分层演进，但不提前创建 AutoGen、完整 MCP、Skills、TUI 等未来阶段空目录或空 adapter。

8. MVP 初始骨架建议：

   ```text
   pyproject.toml
   poetry.lock
   src/forgecli/
     __init__.py
     interfaces/
       cli/
         __init__.py
         app.py
     application/
       __init__.py
     domain/
       __init__.py
     shared/
       __init__.py
       errors.py
       result.py
       ids.py
   tests/
     test_cli_smoke.py
   ```

9. 目标架构按 `docs/02-detailed-design.md` 渐进补齐：`application/services`、`application/agent_loop`、`domain/config`、`tools`、`infrastructure` 等目录只有在对应阶段开始时创建。

## 模块边界说明

配置、工具和 Agent 主循环都是一等模块，不应被简单归入 `infrastructure`。

- `domain/config`：定义配置值对象和校验规则，例如模型、权限、MCP、存储、上下文预算、LLM 供应商、模型列表。
- `application/services/config_service.py`：负责配置加载、合并、查询、更新和迁移。
- `infrastructure/config_sources`：只负责从文件、环境变量、交互式命令输入等来源读取配置。
- `tools`：负责 Tool Registry、Tool Runtime、内置工具定义和 MCP tool 适配，是 Agent 能力面的一部分。
- `infrastructure/shell`、`infrastructure/git`、`infrastructure/filesystem`：只是工具实现依赖的底层适配器。
- `application/agent_loop`：定义 `AgentLoop` ReAct 内核与 `BuiltinAgentLoop`。
  （原写作 `application/workflows` + `AgentWorkflow`；ADR-0003 废弃后按 ADR-0010 更名。）
- `infrastructure/agent_frameworks`：放第三方框架适配器，例如 LangGraph、LangChain。AutoGen 仅作为 V2 Multi-Agent 候选，不进入 MVP 初始骨架。

## 备选方案

- 根目录包布局 `forgecli/`：简单，但测试容易意外导入源码目录而非安装后的包。
- `uv`：速度快，现代化程度高，但团队标准化和发布流程需另行约定。
- `hatch`：适合构建和环境管理，但团队熟悉度可能不如 Poetry。
- 一次性创建完整未来目录：看起来完整，但容易产生空模块和虚假完成感。

## 影响

`src/` 布局让测试更接近真实安装环境。Poetry 通过 `poetry.lock` 保证依赖确定性，适合团队协作和标准化发布。仅创建当前阶段需要的骨架可以降低噪音，但要求每日排期明确何时新增目录。

## 验收标准

- `pyproject.toml` 声明 Python 3.13+。
- 项目包位于 `src/forgecli`，测试位于 `tests`。
- 通过 Poetry 安装、测试、lint、typecheck。
- MVP 初始提交不创建未来阶段空 adapter 或空模块。
- 目录新增必须对应当前阶段任务或已接受 ADR。
