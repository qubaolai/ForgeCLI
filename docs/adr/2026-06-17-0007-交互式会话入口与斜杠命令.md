# ADR-0007：交互式会话入口与斜杠命令

## 状态

Superseded by ADR-0025

## 日期

2026-06-17

## 背景

ForgeCLI 的目标是本地对话式 CLI，而不是每次都通过 `forge <command>` 执行一次性任务。用户应能在仓库目录中启动 ForgeCLI，进入持续会话，通过自然语言和斜杠命令推进任务。

## 决策

1. 在任意工作目录执行 `forge` 时，默认进入交互式会话。

2. 交互式会话绑定当前工作目录作为 workspace root。若当前目录或父目录存在 `.forge/`，优先使用已有项目状态；否则按默认策略创建 session 存储。

3. 会话内支持自然语言输入和斜杠命令。自然语言进入 Agent Turn；斜杠命令由 `IntentRouter` 解析为结构化意图。

4. 配置、模型、状态、恢复等能力在当前 MVP 采用单入口设计：会话内提供 `/config`、`/models`、`/status`、`/resume` 等斜杠命令；Typer 层不保留 `forge config ...`、`forge models ...`、`forge resume ...`、`forge status ...` 等业务子命令。

5. 会话内斜杠命令是交互式体验的主入口，例如 `/plan`、`/act`、`/config`、`/models`、`/status`、`/compact`、`/pause`、`/exit`。

6. Slash command 必须复用 application service。`/config`、`/models`、`/status`、`/resume` 等命令只负责交互输入输出，校验、权限、事件和副作用规则必须位于应用服务。

7. `forge init` 不用于启动对话，也不用于配置初始化；后续保留给项目偏好、项目记忆和仓库约定初始化。

## 交互式命令集

| 命令 | 作用 |
| --- | --- |
| `/help` | 查看当前会话可用命令、参数格式和关键状态。 |
| `/chat` | 切换到对话模式，适合讨论方案、解释代码和澄清需求，不主动执行高风险修改。 |
| `/plan` | 切换到计划模式，生成或更新任务计划、拆分阶段目标和验收标准。 |
| `/act` | 切换到执行模式，允许 Agent 按当前计划推进文件读取、编辑、测试和工具调用。 |
| `/config` | 交互式查看和修改配置，复用 `ConfigService` 的校验、写入和事件记录能力。 |
| `/models` | 查看可用模型、当前运行时模型和模型能力；可通过 `use` 子命令更新运行时默认模型。 |
| `/status` | 查看当前 workspace、session、模式、计划进度、待审批工具调用和上下文预算。 |
| `/compact` | 触发上下文压缩，生成摘要并更新 session state，用于长任务持续推进。 |
| `/resume` | 查看或恢复历史 session；裸 `forge` 启动时也可以提示恢复最近会话。 |
| `/memory` | 查看或更新项目记忆、用户偏好和仓库约定；MVP 可只读或延后实现写入。 |
| `/tools` | 查看内置工具、工具权限、最近工具调用和工具可用性诊断。 |
| `/mcp` | 查看 MCP server 状态、连接结果和暴露的工具；MVP 可先提供诊断视图。 |
| `/pause` | 暂停当前执行，保留 session state，允许之后继续恢复。 |
| `/exit` | 安全退出会话，刷新事件日志、状态文件和必要摘要。 |

## 备选方案

- 每次使用 `forge <command>`：适合脚本，但不符合持续对话体验。
- 只提供 `forge chat`：显式但多余，不符合 CLI Agent 的默认交互预期。
- 在会话内不支持斜杠命令：实现简单，但模式切换、压缩、暂停和诊断不够高效。

## 影响

裸 `forge` 成为主入口，CLI 需要实现交互式 REPL、输入解析、会话恢复提示、斜杠命令帮助和安全退出。当前 MVP 不维护业务 Typer 子命令，可以减少路由和测试成本；脚本友好入口作为后续阶段重新评估的能力，不进入当前开发周。

## 验收标准

- `forge` 在当前目录启动交互式会话。
- 普通输入写入当前 session 的 `events.jsonl`。
- `/plan`、`/act`、`/config`、`/models`、`/status`、`/pause`、`/exit` 至少有 MVP 行为。
- `/config` 复用同一配置服务。
- `/models` 复用同一模型目录服务。
- 斜杠命令和自然语言输入在事件日志中可区分。
- 会话退出后可通过再次 `forge` 或 `/resume` 恢复。
